# archdi-pkg

> **Moved**: the menus are now in the `pkg/` folder of [sevenzip2/archdi](https://github.com/sevenzip2/archdi), with their history.
> This repository is kept read-only so older archdi launchers keep working (they download `pkg.tar` from here).
> Run `archdi` once to update the launcher, it then uses the new location.

This project is part of archdi.<br>
look at archdi project to use it : https://github.com/sevenzip2/archdi

If you want request a new features for archdi use issues on this project (https://github.com/sevenzip2/archdi-pkg/issues).

Other way is to fork this project, add features and request a pullback.<br>
For testing, you can use:<br>
archdi -t {githubusername} {archdi-pkg branch name}<br>
as example :<br>
archdi -t sevenzip2 master
